## 第一章 文档概述

### 1.1 项目背景

**Suno-Cover-Arranger**（大师来了）是一款专为 Suno AI 音乐创作者设计的纯前端辅助工具，目前已具备「大师做编曲」（Styles/Lyrics 提示词生成）和「大师写歌词」（11 位大师风格卡驱动的 AI 作词）两大核心模块。

当前项目聚焦于**提示词生成**层面，尚未覆盖**音频预处理**环节。许多 Suno 用户在翻唱创作中存在一个核心痛点：

> 上传的参考音频被 Suno 等 AI 音乐平台的音频指纹检测识别为受版权保护的原曲，导致翻唱失败或受限。

**Cover Boy** 是一个专门解决此问题的 AI 翻唱预处理流水线工具，其核心目标是通过频谱指纹混淆（Stage 2）和保音调变速（Stage 3）来绕过音频指纹检测。本方案旨在将 Cover Boy 的核心能力移植到 Suno-Cover-Arranger 项目中，为用户提供「提示词生成 → 音频预处理 → 一键上传 Suno」的完整创作闭环。

### 1.2 目标

| 目标        | 描述                                                                            |
| --------- | ----------------------------------------------------------------------------- |
| 零安装       | 与现有项目一致，纯前端架构，用户打开网页即可使用                                                      |
| 功能完整      | 完整覆盖 Stage 2（频谱指纹混淆）+ Stage 3（0.5x 保音调变速）+ MP3 编码输出                           |
| 性能可接受     | 192 秒音频处理总耗时控制在 60 秒以内                                                        |
| 与现有项目无缝集成 | 遵循 Umi\@4 + Ant Design Pro + TypeScript 技术栈，复用现有 AI Provider 和 IndexedDB 基础设施 |
| 降级可用      | Web Worker 不可用时自动降级，保证基础功能可用                                                  |

### 1.3 适用范围

* **浏览器支持**：Chrome 113+、Edge 113+、Firefox 120+、Safari 16.4+

* **音频格式**：MP3、WAV、FLAC、M4A（通过浏览器 `AudioContext.decodeAudioData()` 解码）

* **音频时长**：第一版限制 5 分钟以内音频（整段 FFT 策略），后续版本支持任意长度（STFT 分块）

## 第三章 Stage 2：频谱指纹混淆

### 3.1 功能概述

Stage 2 是翻唱预处理的**核心技术步骤**。它通过对音频信号进行频域处理（EQ 滤波 + 动态压缩 + 本底噪声注入 + Peak Limiter），改变音频的频谱指纹特征，使其在保持听觉相似性的前提下，在机器指纹匹配层面变得"不可识别"。

### 3.2 输入/输出

| 项目     | 描述                                       |
| ------ | ---------------------------------------- |
| 输入     | `AudioBuffer`（浏览器解码后的音频对象）               |
| 输出     | `Float32Array[]`（混淆后的音频声道数据，保持原始采样率和声道数） |
| FFT 策略 | 整段 FFT + 补零到 2 的幂（与 CUDA 版一致），第一版限制 5 分钟 |

### 3.3 三种预设参数

> 参数来源：严格复刻 `cuda_obfuscator.py` 中的 `PRESETS` 字典。

| 参数           | Light                     | Medium  | Heavy   |
| ------------ | ------------------------- | ------- | ------- |
| EQ 频段数       | 18 段                      | 18 段    | 18 段    |
| 低切频率         | 50Hz                      | 40Hz    | 60Hz    |
| 高切频率         | 16000Hz                   | 15000Hz | 14000Hz |
| 压缩阈值（线性）     | 0.125                     | 0.1     | 0.063   |
| 压缩比          | 3.0                       | 4.0     | 6.0     |
| 噪声底电平        | -65dB                     | -60dB   | -55dB   |
| Peak Limiter | 峰值 > 0.99 时 × (0.95/peak) | 同       | 同       |

### 3.4 核心算法流程

```
AudioBuffer
  │
  ├─ 分声道处理（loop channels）
  │
  ├─ 整段取数据 + 补零到 2 的幂
  │
  ├─ 步骤 1: FFT 转频域（实数 FFT，WebFFT）
  │   fftr(signal) → 正频率半谱 [N/2 + 1]
  │
  ├─ 步骤 2: EQ 频域滤波（18 段线性插值增益曲线）
  │   spectrum[i] = spectrum[i] × eq_gain[i]
  │
  ├─ 步骤 3: IFFT 回时域
  │   irfft(spectrum) → 时域信号
  │
  ├─ 步骤 4: 动态压缩（时域，逐采样点，线性阈值）
  │
  ├─ 步骤 5: 本底噪声注入（时域，Box-Muller 高斯噪声）
  │
  ├─ 步骤 6: Peak Limiter（峰值 > 0.99 → × 0.95/peak）
  │
  └─ 输出 Float32Array[]
```

## 第四章 Stage 3：保音调变速

### 4.1 功能概述

Stage 3 将 Stage 2 输出的音频进行 **0.5 倍速时间拉伸**，在保持音高不变的前提下将播放时间延长至 2 倍。这是混淆时间域指纹的有效手段。

### 4.2 输入/输出

| 项目   | 描述                                           |
| ---- | -------------------------------------------- |
| 输入   | `Float32Array[]`（Stage 2 输出，混淆后的音频声道数据）      |
| 输出   | `Float32Array[]`（0.5x 变速后，音高不变，长度 = 原长度 × 2） |
| 速度因子 | 0.5（tempo = 0.5）                             |
| 音高因子 | 1.0（保持不变）                                    |

### 4.3 算法选择：Phase Vocoder（推荐）

使用 SoundTouchJS 的相位声码器引擎，对应 FFmpeg `rubberband` 滤镜：

| 参数     | 值    | 说明                          |
| ------ | ---- | --------------------------- |
| FFT 帧长 | 2048 | 频率分辨率 = 44100/2048 ≈ 21.5Hz |
| 重叠因子   | 4    | 75% 重叠，分析跳步 = 2048/4 = 512  |
| 窗函数    | Hann | 满足 COLA 约束                  |

**备选方案**：WSOLA 模式（对应 FFmpeg `atempo`），在 Phase Vocoder 内存不足时自动降级。

## 第五章 MP3 编码输出

### 5.1 为什么选 MP3 而非 WAV

| 格式          | 192s 音频 → 384s（0.5x 后） | 下载体验         |
| ----------- | ---------------------- | ------------ |
| WAV 16-bit  | \~67.7 MB              | 极差，浏览器下载耗时过长 |
| MP3 128kbps | \~6.1 MB               | 优秀，几秒内完成下载   |

### 5.2 lamejs 编码参数

| 参数    | 值          | 说明           |
| ----- | ---------- | ------------ |
| 声道数   | 2（立体声）     | 与输入保持一致      |
| 采样率   | 44100 Hz   | 标准 MP3 采样率   |
| 比特率   | 128 kbps   | CBR 恒定比特率    |
| 编码块大小 | 1152 采样点   | 576 的倍数，推荐值  |
| 输入格式  | Int16Array | 16-bit 有符号整数 |

## 第九章 核心模块实现

### 9.1 流水线编排（pipeline.ts）

流水线编排负责协调整个音频处理流程，是「翻唱预处理」功能的入口模块：

```typescript
// src/services/audio/pipeline.ts

/**
 * 翻唱预处理完整流水线
 * 顺序执行：音频解码 → Stage 2 频谱混淆 → (可选) Stage 3 变速 → MP3 编码
 */
export async function runCoverPreprocessPipeline(
  input: PipelineInput
): Promise<PipelineOutput> {
  // 阶段 0: 音频解码
  input.onProgress?.({ stage: 'decode', progress: 0, label: '解码中...' });
  const audioCtx = new AudioContext();
  const arrayBuffer = await input.audioFile.arrayBuffer();
  const audioBuffer = await audioCtx.decodeAudioData(arrayBuffer);
  input.onProgress?.({ stage: 'decode', progress: 10, label: '解码完成' });

  // Stage 2: 频谱指纹混淆（Web Worker 中执行）
  input.onProgress?.({ stage: 'stage2', progress: 10, label: '频谱混淆中...' });
  const obfuscated = await runStage2InWorker(audioBuffer, input.preset, (p) => {
    input.onProgress?.({ stage: 'stage2', progress: 10 + p * 0.55, label: '频谱混淆中...' });
  });

  // Stage 3: 保音调变速（可选，根据 speedMode 决定）
  let processed = obfuscated;
  let speedFactor = 1.0; // 时长倍数，默认不变
  if (input.speedMode === 'slowdown') {
    input.onProgress?.({ stage: 'stage3', progress: 65, label: '0.5x 降速中...' });
    processed = await runStage3InWorker(obfuscated, audioBuffer.sampleRate, 0.5, (p) => {
      input.onProgress?.({ stage: 'stage3', progress: 65 + p * 0.30, label: '0.5x 降速中...' });
    });
    speedFactor = 2.0; // 0.5x → 时长变为 2 倍
  } else if (input.speedMode === 'speedup') {
    input.onProgress?.({ stage: 'stage3', progress: 65, label: '2x 加速中...' });
    processed = await runStage3InWorker(obfuscated, audioBuffer.sampleRate, 2.0, (p) => {
      input.onProgress?.({ stage: 'stage3', progress: 65 + p * 0.30, label: '2x 加速中...' });
    });
    speedFactor = 0.5; // 2x → 时长变为 0.5 倍
  }

  // 阶段 4: MP3 编码
  const encodeStartProgress = input.speedMode !== 'none' ? 95 : 65;
  input.onProgress?.({ stage: 'encode', progress: encodeStartProgress, label: 'MP3 编码中...' });
  const mp3Blob = encodeMP3(processed, audioBuffer.sampleRate);
  input.onProgress?.({ stage: 'done', progress: 100, label: '完成！' });

  audioCtx.close();
  return {
    mp3Blob,
    originalDuration: audioBuffer.duration,
    processedDuration: audioBuffer.duration * speedFactor,
    preset: input.preset,
  };
}
```

### 9.3 Stage 2 核心实现

```typescript
// src/services/audio/stage2/index.ts

/**
 * Stage 2 主函数 — 整段 FFT 策略，与 CUDA 版一致
 * 第一版限制 5 分钟以内音频
 */
function processStage2(audioBuffer: AudioBuffer, preset: PresetLevel): Float32Array[] {
  const sr = audioBuffer.sampleRate;
  const channels = audioBuffer.numberOfChannels;
  const sigLen = audioBuffer.length;
  const fftSize = nextPow2(sigLen);  // 补零到 2 的幂
  const cfg = PRESETS[preset];

  // 初始化 FFT 引擎
  const fft = new WebFFTBackend(fftSize);

  // 预计算 EQ 增益曲线
  const eqCurve = buildEqGainCurve(sr, fftSize, cfg.eq_bands);

  const outputChannels: Float32Array[] = [];

  for (let ch = 0; ch < channels; ch++) {
    const input = audioBuffer.getChannelData(ch);

    // 步骤 1: 整段取数据 + 补零到 fftSize
    const padded = new Float32Array(fftSize);
    padded.set(input);

    // 步骤 2: 实数 FFT → 频域
    const spectrum = fft.rfft(padded);

    // 步骤 3: EQ 频域滤波
    applyEqFilter(spectrum, eqCurve);

    // 步骤 4: IFFT → 回时域
    const timeDomain = fft.irfft(spectrum, sigLen);

    // 步骤 5: 动态压缩
    applyCompressor(timeDomain, cfg.threshold, cfg.ratio);

    // 步骤 6: 本底噪声注入
    applyNoiseFloor(timeDomain, cfg.noise_floor_db);

    // 步骤 7: Peak Limiter
    applyPeakLimiter(timeDomain);

    outputChannels.push(timeDomain);
  }

  fft.dispose();
  return outputChannels;
}
```

### 9.4 Stage 3 核心实现

```typescript
// src/services/audio/stage3/index.ts

/**
 * Stage 3 主函数
 * 使用 SoundTouchJS 相位声码器实现保音调变速
 * @param inputChannels - 输入声道数据
 * @param sampleRate - 采样率
 * @param tempo - 速度因子: 0.5=降速至半速, 2.0=加速至双倍速
 */
function processStage3(
  inputChannels: Float32Array[],
  sampleRate: number,
  tempo: number
): Float32Array[] {
  const st = new SoundTouch({
    sampleRate,
    sampleBufferType: Float32Array,
    stretchFactory: createPhaseVocoderFactory(2048, 4),
  });

  st.tempo = tempo;   // 速度因子: 0.5 或 2.0
  st.pitch = 1.0;     // 保持音高不变

  const outputChannels: Float32Array[] = [];

  for (let ch = 0; ch < inputChannels.length; ch++) {
    st.clear();
    st.putSamples(inputChannels[ch], inputChannels[ch].length);
    st.flush();

    const output = new Float32Array(st.sampleCount);
    st.receiveSamples(output, output.length);
    outputChannels.push(output);
  }

  st.clear();
  return outputChannels;
}
```

### 9.5 MP3 编码

```typescript
// src/services/audio/encoder/mp3-encoder.ts

/**
 * 将 Float32Array 声道数据编码为 MP3 Blob
 * 使用 lamejs，128kbps CBR，44.1kHz
 */
function encodeMP3(channels: Float32Array[], sampleRate: number, kbps = 128): Blob {
  const numChannels = channels.length;
  const totalSamples = channels[0].length;
  const blockSize = 1152;

  const encoder = new Mp3Encoder(numChannels, sampleRate, kbps);
  const mp3Data: Int8Array[] = [];

  if (numChannels === 1) {
    const input = float32ToInt16(channels[0]);
    for (let i = 0; i < totalSamples; i += blockSize) {
      const chunk = input.subarray(i, Math.min(i + blockSize, totalSamples));
      const mp3buf = encoder.encodeBuffer(chunk);
      if (mp3buf.length > 0) mp3Data.push(mp3buf);
    }
  } else {
    const left = float32ToInt16(channels[0]);
    const right = float32ToInt16(channels[1]);
    for (let i = 0; i < totalSamples; i += blockSize) {
      const end = Math.min(i + blockSize, totalSamples);
      const mp3buf = encoder.encodeBuffer(left.subarray(i, end), right.subarray(i, end));
      if (mp3buf.length > 0) mp3Data.push(mp3buf);
    }
  }

  const finalBuf = encoder.flush();
  if (finalBuf.length > 0) mp3Data.push(finalBuf);

  return new Blob(mp3Data, { type: 'audio/mp3' });
}

### 12.1 降级链

```
检测 Web Worker 支持
  ├─ 支持 → 在 Worker 中执行（推荐）
  └─ 不支持 → 主线程执行（显示警告提示）

  ├─ 'none' → 跳过 Stage 3，直接进入 MP3 编码
  ├─ 'slowdown' → 执行 Stage 3（tempo=0.5）
  └─ 'speedup' → 执行 Stage 3（tempo=2.0）

检测 Stage 3 Phase Vocoder 内存（仅在 speedMode ≠ 'none' 时）
  ├─ 内存充足 → Phase Vocoder 模式（质量最佳）
  └─ 内存不足 → 自动降级为 WSOLA 模式

检测音频时长
  ├─ ≤ 5 分钟 → 整段 FFT（与 CUDA 一致）
  └─ > 5 分钟 → 提示用户截取或等待后续版本 STFT 分块
