
## 「大师看和弦」卡 10% 问题最终解决

### 根因
Mako（UmiJS 的 Rust 编译引擎）对 Web Worker 支持有问题：
- Mako 把 Worker 编译为 IIFE 格式，注入了 HMR/chunk-loading runtime
- 经典 Worker `new Worker(url)`（无 `type: 'module'`）+ mako 的 IIFE 可以正常执行
- `importScripts` 在 mako 编译后保留并正常可用

### 最终方案（经 Playwright + dist 生产构建验证）
- Worker: 经典 Worker 模式 + `importScripts` 加载 UMD 版 essentia
- essentia 资源: 通过 `scripts/copy-essentia.js` 复制到 `public/essentia-wasm/`
- Mako: 保持开启（`mako: {}`），不关闭

### 验证结果
```
Worker started → essentia-wasm.web.js loaded → essentia.js-core loaded ✅
```

### 用户侧问题
Dev server 不稳定（进程退出）是由于之前的 Mako/Webpack 切换和 MFSU 配置残留导致。清缓存后 `pnpm dev` 即可。
