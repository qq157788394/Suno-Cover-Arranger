## Essentia.js 和弦检测 debug — 完整 pipeline 打通
- Key + BPM：KeyExtractor + BeatTrackerMultiFeature → 正确
- SpectralPeaks 根因：Core API 签名 `(spectrum, magnitudeThreshold, maxFrequency, maxPeaks, minFrequency, orderBy, sampleRate)`，sampleRate 在第 7 参而非第 2。此前传 48000 到 magnitudeThreshold，滤掉所有峰值
- Spectrum→SpectralPeaks 链：Windowing→Spectrum→SpectralPeaks，Spectrum 返回 `{spectrum: VectorFloat}` 非裸 VectorFloat
- 逐帧 HPCP：frameSize/Windowing/Spectrum 需显式传 4096，默认 1024/2048 尺寸不匹配
- 和弦匹配：弃用 ChordsDetectionBeats（返回 NaN），用自有 chord-matcher(The Backend agent's code) + Viterbi 通过。basic 级别 24 和弦余弦相似度匹配 + HMM 转移矩阵平滑
- 和弦聚合：每 2 拍半小节 + 节拍对齐 + 最小 1 秒段落
- 强拍检测：OnsetRate 计算每拍 onset 密度，top 25% 标记强拍（×2 和弦投票权重）
- 级数转换：Romanizer.annotateProgression() 批量转罗马数字
- Canvas 闪烁修复：currentTime 走 ref，draw callback 不依赖它→rAF 循环不每帧重启
- Canvas 性能：二分查找可见节拍范围 + 高密度时只画强拍线
- 生产构建：`pnpm build` 出 dist/，python http.server 静态服务 + Playwright 自动化测试
- 测试数据：tests/chord-features.json（百年孤寂，E major 152BPM，500帧 12-bin chroma）
